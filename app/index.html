COM port not showing?

      

        

          This browser can't show its own port picker – that's fine: use the COM ports in the dropdown, which come straight from Windows through the tester server.
        

        
    
          
  1. The dropdown lists the COM ports Windows sees (e.g. COM49 – USB Serial Port (FTDI)). Press ↻ after plugging in the adapter, pick the port and press Connect.
    2. 
          
  2. Plug in the FTDI adapter and check Device Manager → Ports (COM & LPT) shows USB Serial Port (COMx). Greyed-out entries (View → Show hidden devices) are adapters that are not connected.
    3. 
          
  3. Only "USB Serial Converter" under Universal Serial Bus controllers, no COM port? Right-click it → Properties → Advanced → tick Load VCP → OK, then unplug and replug the adapter.
    4. 
          
  4. Close other programs that use the port: Jofemar Formulario JConnect, DistribuidorRS232, PuTTY, Arduino IDE, the Signifi kiosk app. The port can be open in only one program at a time.
    5. 
          
  5. Still empty? Unplug the adapter, wait 5 s, plug it into a different USB port, then press ↻ again.
    6. 
          
  6. Port opens but "JSD not responding"? Check the JSD is powered, the RS232 cable goes to the JSD's CON3 (RS232) connector (Jofemar harness 88003118), and the baud rate is 9600.
