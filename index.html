Full version on the Linux NUC recommended

Everything the Windows tester does – Odoo SO lookup, NUC serial number, barcode scanner / TWN4 / HID reader check, cameras, lanes – installed straight from this page (no USB stick). Open Terminal on the NUC (Ctrl+Alt+T), paste this line and press Enter:

  1. It asks once for the UNLOCK passphrase. That unlocks the Odoo API key and the sudo password (kept encrypted on this site), so Odoo, the FTDI serial port and the NUC serial number work without typing anything else.
  2. It installs Node.js and the tester into your home folder, runs it in the background and puts a Lane Tester icon on the desktop (full screen, Alt+F4 closes).
  3. From then on the same command runs by itself at every login: it updates the tester if there is a new version and opens it full screen. No internet? The installed tester still opens.
  4. Once installed, the web app below also switches to the full version automatically.

Web app (any PC, limited)

Runs in Google Chrome or Microsoft Edge on the kiosk NUC. Nothing is installed on the system and no USB stick is needed. Once installed it opens in its own full-screen window and keeps working when the network drops.

▶ Open Lane Tester

If the Install button does not appear, open the tester and use Chrome's menu ⋮ → Cast, save and share → Install page as app (or the install icon in the address bar).

Steps on the NUC

  1. Open this link in Chrome (type it, or scan the QR code with the kiosk's barcode scanner into the address bar).
  2. Click Install app (or Open Lane Tester to use it without installing).
  3. Enter the tester name and SO number, choose Spark XL or Companion.
  4. Plug the FTDI USB-RS232 adapter into the JSD, click + Port and pick the FTDI port. Chrome remembers it.
  5. Click Connect, then Scan lanes and Test all lanes.

Desktop shortcut – opens in kiosk mode

Installing the app (above) adds Lane Tester to the app launcher and opens it in its own window; it switches to full screen on the first tap. For a true kiosk window (no browser bars, full screen, Alt+F4 to exit) download a desktop shortcut for this PC:

  1. Linux: save lane-tester-kiosk.desktop into Desktop (Files → Downloads → move it to Desktop), right-click it → Allow Launching. Double-click to start.
  2. Windows: save Lane Tester (kiosk).cmd on the Desktop and double-click it (choose More info → Run anyway if SmartScreen asks).
  3. The kiosk shortcut uses its own Chrome profile: pick the FTDI port once with + Port there; its settings and saved results are kept separately from normal Chrome.

–No NUC serial number or USB device list (barcode scanner, TWN4, HID reader): browsers are not allowed to read them
Linux NUC: Chrome can only open the FTDI port if the logged-in user may use serial ports (member of the dialout group). If Connect fails with “Failed to open serial port”, ask IT to add the kiosk user to dialout and log in again.
